Why This File Exists

This file implements the exact identification and interpretation workflow we discussed:

  1. Use pre-determined baseline governance capacity as the moderator.
  2. Estimate the moderation model first on overall data, then by sector, for both admin levels.
  3. Run lag sensitivity over candidate values of t.
  4. Report interpretable quantities:
  • marginal effect of fragmentation at capacity p25, p50, p75
  • sign-switch threshold
  • placebo model with future fragmentation

Advisor note on a reasonable t

  • If this is annual data, use t=1 as baseline for identification and interpretability, and treat t=2,3 as persistence checks.
  • If this is 5-year data, t=1 is effectively a 5-year lag and is the practical baseline.
  • A “reasonable” t is the one that balances:
    • signal (interaction effect not vanishing)
    • sample retention
    • temporal plausibility for the outcome mechanism

This file gives all three directly so you can defend your choice in the chapter.
